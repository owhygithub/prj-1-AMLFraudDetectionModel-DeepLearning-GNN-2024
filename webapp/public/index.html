About the data

The published experiments used the IBM synthetic AML dataset, which is far too large to ship to a browser. This demo is trained on a smaller generated dataset that plants the same four laundering shapes the real data is built from: fan-out (structuring a sum out to many mules), fan-in (consolidating it back), cycles (round-tripping), and chains (layering it forward). Each fires in a tight time window.

So the numbers on this page are not the numbers in the paper, and they are easier, because planted patterns are cleaner than real laundering. The model, the arithmetic and the weights are real. See RESULTS.md for the actual experiments, including the defects found in the original code.
